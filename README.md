# Jocket A股智能分析工具

这是一个用于研究辅助的 A 股智能分析项目，包含命令行个股分析和 Streamlit 可视化界面。

## 数据源

当前版本支持多源自动路由：

- `auto`：默认模式，优先使用 a-stock-data 直连源、百度股市通、AkShare、efinance、同花顺、Yahoo Finance 自动回退。
- `baidu`：使用百度股市通 K 线，返回值包含 MA5/MA10/MA20，可作为 AkShare 不稳定时的日线兜底。
- `ths`：使用同花顺机器可读日线接口。
- `efinance`：使用 efinance 行情接口。
- `akshare`：只使用 AkShare。
- `yfinance`：只使用 Yahoo Finance，适合网络环境无法访问国内行情源时兜底。

说明：项目已接入 `simonlin1212/a-stock-data` V3.1 的直连数据源思路，补充腾讯财经、百度股市通、东财 datacenter/push2、同花顺热点、财联社、巨潮公告等公开接口。AkShare 的 A 股历史行情接口常用东方财富源，部分 macOS / Python / 网络环境可能出现 SSL 错误；Clash、VPN 或系统代理也可能让 Python 请求报 `ProxyError`。项目默认在行情下载进程内跳过 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` 等代理环境变量，并保留 SSL 绕过补丁和自动兜底。

## 界面功能

界面入口收敛为三个核心功能：`AI行情`、`个股分析`、`市场情绪`。

### 个股分析

输入股票代码，例如：

```text
300750
600519
000001
```

系统会输出：

- 实时价（efinance 实时行情可用时会替换当天日线；不可用时默认报错，不静默回落到旧收盘）
- 短线评分
- 中长线评分
- 综合评分
- K线图及 MA20 / MA60 / MA120
- 评分拆解
- 风险信号
- 最近行情数据
- a-stock-data 高价值信号卡片：估值压力、预期兑现难度、资金流验证、龙虎榜强度、解禁压力、筹码集中度、融资情绪、大宗交易折溢价、公告事件强度、热点归因匹配。

### 市场情绪

市场情绪页用于复盘全市场涨停生态、情绪周期、板块梯队和次日条件观察池。页面支持选择交易日、观察窗口，并可按需强制刷新公共源或补齐历史缓存。新增“主线与资金验证”卡片组，用同花顺热点、北向资金、全市场龙虎榜、行业轮动、指数/ETF 风险偏好验证市场主线是否具备交易含义。

### AI行情

`AI行情` 页面把项目内的 `Awesome-finance-skills` 能力接入为自然语言对话助手：

- 读取 `alphaear-deepear-lite` 的 DeepEar Lite 实时金融信号。
- 结合项目已有公开新闻/热点聚合能力生成实时上下文。
- 读取 a-stock-data 个股/市场信号卡片，用“卡片结论 + 阈值 + 来源 + 更新时间”支持估值、资金、公告、龙虎榜、北向、行业轮动等问答。
- 可手动触发 `QQQ` 量化回测 skill，自动补充近 250 / 60 交易日策略回测、支撑压力、止损位、突破确认位、BOLL / ATR / KDJ 和条件式交易计划。
- 项目内置 `src/skill/Awesome-finance-skills/skills` 与 `src/skill/finance-quant-skills/skills`，部署环境无需依赖根目录的本地参考仓库。
- 使用 Gemini 原生 API 生成回答，并在界面显示当前连接状态。

启动前需要配置 API token。推荐复制 `.env.example` 为 `.env`，再填入本地密钥；`.env` 已被 `.gitignore` 忽略，不会进入 Git。

```bash
cp .env.example .env
```

支持的环境变量：

- `GEMINI_API_KEY`：Gemini 原生 API key。
- `GEMINI_MODEL`：Gemini 模型，默认 `gemini-2.5-flash`。

也可以在 `config.yaml` 的 `ai_market` 段里修改 Gemini 的模型、base URL、温度和输出长度。请不要把真实 API key 写入 `config.yaml`、代码或 README。

## 评分模型说明 / Scoring Methodology

评分用于研究辅助和观察池排序，不构成投资建议，也不代表确定收益。短线高分不等于立即买入，仍需结合买入位置、止损、市场环境和仓位管理。

### 短线评分模型

短线评分为 100 分制，强调最近价格结构、量价配合、动量和可交易性。

- 趋势强度，满分 20：参考 `close > MA20`、`MA5 > MA10 > MA20`、`close > MA60`、近 5 日/20 日涨跌幅、距离近期高点。均线多头和价格站上关键均线加分，涨幅过高会提示追高风险。
- 量价配合，满分 20：参考当日涨跌幅、成交量、5 日/20 日均量、量比。放量上涨加分，放量下跌或高量滞涨扣分。
- 动量指标，满分 15：参考 RSI、MACD DIF/DEA/Histogram、KDJ。RSI 50-70 偏强，RSI 高于 80 视为过热风险；MACD 红柱扩大和 DIF 高于 DEA 加分。
- 流动性，满分 15：参考成交额、成交量、换手率可用性和近 20 日平均成交额。成交额太低不适合短线，成交活跃说明买卖执行更容易。
- 行业/题材/资金催化，满分 15：基础引擎无外部上下文时使用近 5/20/60 日价格动量作为代理；应用层取得数据后，会替换为所属板块/概念涨幅、板块资金净流入、个股主力资金流、新闻/公告热度与热点归因的综合评分。
- 风险控制，满分 15：风险控制分越高，代表当前技术风险越低；分数越低，代表追高、回撤或波动风险越大。参考 RSI 过热、近 20 日涨幅、MA20 偏离、振幅、放量下跌和最大回撤。

短线评分区间含义：

- 85-100：短线强势，但需检查是否追高；适合优先观察，不等于直接买入。
- 70-84：短线偏强，可进入观察池，等待回踩或确认信号。
- 55-69：中性偏弱，仅适合继续跟踪，不作为优先标的。
- 40-54：短线信号不足，除非有外部催化，否则不建议优先关注。
- 0-39：短线弱势或风险较高，建议回避。

### 中长线评分模型

中长线评分同样为 100 分制。当前页面会优先使用基本面与估值模块获取到的 ROE、ROA、D/E、收入增长、净利润增长、PE、PB、股息率和简化 DCF 来替换旧的质量/成长/估值占位项；如果这些数据不可用，则回退为价格趋势代理和保守占位分，不能单独作为中长期投资依据。

- 财务质量，满分 15：优先使用 ROE、ROA、D/E 衡量盈利能力和杠杆水平；缺失时使用保守占位并提示数据不足。
- 成长表现，满分 15：优先使用收入增长和净利润增长评分；缺少可比财务序列时使用保守占位。
- 估值与股息，满分 10：综合 PE、PB、股息率和简化 DCF；PS 作为辅助展示指标。
- 长期趋势，满分 35：参考 `close > MA60`、`close > MA120`、`close > MA250`、MA60/MA120 方向、近 60/120 日涨跌幅和回撤控制。
- 波动稳定性，满分 10：参考近 60 日波动率、最大回撤和收盘价偏离均线程度。
- 风险控制，满分 15：参考长期趋势破位、大幅回撤、高波动、短期涨幅过快和数据源完整性。

中长线评分区间含义：

- 85-100：趋势和基本面代理指标较强，适合纳入中长期研究池。
- 70-84：中长期结构较好，但仍需补充财务和估值验证。
- 55-69：中性，需要等待趋势或基本面进一步确认。
- 40-54：中长期吸引力不足。
- 0-39：中长期风险较高或数据质量不足。

### 综合评级规则

- 短线 >= 80 且风险控制分 >= 10：短线强势观察。
- 短线 >= 70 且风险控制分 < 10：短线偏强但风险较高。
- 中长线 >= 75 且长期趋势分较高：中长期研究池。
- 短线 < 55 且中长线 < 55：暂不优先关注。
- 如果财务和估值数据可用，会参与中长线评分；行业热度、主力资金或新闻催化按可得性进入短线外部信号维度，缺失时只让对应子项不加分，并在限制说明中提示。

### 当前版本数据限制

- yfinance 可提供的财务和估值字段已经用于页面评分，但部分 A 股本地口径、扣非净利润、分红明细和历史估值分位可能缺失。
- 行业名称 / Sector、所属板块/概念、板块即时涨幅、可匹配板块资金流、个股主力资金流、新闻/公告热度和热点归因会并入短线外部信号评分；无法取得的子项只是不加分，并在限制说明中单独提示。
- 同花顺日线接口提供的是行情和部分换手率数据，不等同于完整基本面数据。

## 基本面与估值模块说明

个股分析页新增“公司基本面与估值快照”，用于补充行情和技术评分之外的研究信息。该模块只展示已获取到的数据，缺失字段会显示“暂未获取”或“N/A”，不会用 0 或假设值冒充真实财务数据。

### 公司基本信息字段

公司画像展示股票代码、股票名称、交易所、所属市场、行业、Sector、主营业务简介、上市时间、总市值、流通市值、总股本、流通股本、实时价/最新收盘价、数据更新时间和数据源。A 股市场类型会根据代码后缀和代码段识别为沪市、深市、创业板、科创板等；无法识别时会标记为当前数据源暂不支持。

### 财务数据来源

- yfinance：优先用于公司简介、行业、Sector、市值、PE、PB、股息率、ROE、ROA、资产负债表、利润表、现金流量表等可用字段。
- a-stock-data 直连源：用于腾讯 PE/PB/市值/换手/涨跌停、同花顺一致预期、东财研报、东财资金流、龙虎榜、解禁、融资融券、大宗交易、股东户数、分红、巨潮公告、财联社和东财 7x24 快讯。
- efinance：用于获取 A 股所属板块/概念和板块即时涨幅，例如通信设备、CPO 概念、地区板块等，并参与“行业/题材/资金催化”评分。
- AkShare：用于补充 A 股公司资料和财务信息，但用户环境中 AkShare/东方财富接口可能出现 SSL 或代理错误，因此所有调用均带异常保护。
- AkShare 板块资金流：用于补充行业/概念资金净流入、领涨股等信息；如果东方财富接口因 SSL/代理失败，会自动跳过，不影响页面主体。
- efinance / 同花顺：当前主要用于行情数据，后续可扩展为基本信息补充源。
- 本地缓存：Streamlit 会对基本面请求做短期缓存，减少重复请求。

### 估值指标计算方式

- PE TTM：优先使用数据源返回值；缺失时尝试使用 `当前市值 / 最近年度归母净利润` 或 `最新价格 / EPS`。
- PE 静态：`当前市值 / 最近年度归母净利润`。
- PB：优先使用数据源返回值；缺失时使用 `当前市值 / 股东权益` 或 `最新价格 / BVPS`。
- PS：`当前市值 / 最近年度营业收入`。
- ROE：优先使用数据源返回值；缺失时使用 `净利润 / 股东权益`。
- ROA：优先使用数据源返回值；缺失时使用 `净利润 / 总资产`。
- D/E：优先使用数据源返回值；缺失时使用 `总负债 / 股东权益` 作为代理，并在页面中提示该口径限制。
- 股息率：优先使用数据源返回值；缺失时显示“暂无分红数据”。

### 简化 DCF 假设

DCF 模块明确标记为“简化 DCF 估算”。默认参数为：

- 高增长期年数：5 年。
- 现金流增长率：5%。
- 永续增长率：2%。
- 折现率：10%。
- 安全边际：20%。

计算时优先使用自由现金流；自由现金流缺失时使用经营现金流净额作为代理。若现金流或总股本缺失，页面会显示“当前数据源缺少现金流数据，暂无法计算 DCF。”DCF 结果对增长率、折现率和现金流口径高度敏感，不应作为单独投资依据。

### Ratings Snapshot 雷达图评分规则

雷达图使用 1-5 分制，不可得指标显示 N/A，且不纳入 Overall Score。

- DCF：当前价格相对简化 DCF 估算价值折价越大，分数越高；明显高估为低分。
- ROE：`>20%` 为 5 分，`15%-20%` 为 4 分，`10%-15%` 为 3 分，`5%-10%` 为 2 分，低于 5% 或为负为 1 分。
- ROA：`>10%` 为 5 分，`7%-10%` 为 4 分，`4%-7%` 为 3 分，`1%-4%` 为 2 分，低于 1% 或为负为 1 分。
- D/E：越低越好，`<0.5` 为 5 分，`0.5-1.0` 为 4 分，`1.0-1.5` 为 3 分，`1.5-2.5` 为 2 分，`>2.5` 为 1 分。
- P/E：`10-25` 且利润为正为 5 分，`25-40` 或 `5-10` 为 4 分，`40-60` 为 3 分，`>60` 为 2 分，负值或无法计算为 1 分。
- P/B：`1-3` 为 5 分，`3-5` 或 `0.5-1` 为 4 分，`5-8` 为 3 分，`>8` 为 2 分，`<=0` 或无法计算为 1 分。
- Dividend Yield：`>4%` 为 5 分，`3%-4%` 为 4 分，`1.5%-3%` 为 3 分，`0%-1.5%` 为 2 分，无分红或不可得为 1 分。
- Revenue Growth / Net Profit Growth：`>20%` 为 5 分，`10%-20%` 为 4 分，`0%-10%` 为 3 分，`-10%-0%` 为 2 分，低于 -10% 为 1 分。

Overall Score 为可用指标平均值，并转换为评级：4.5-5.0 为 A，4.0-4.4 为 A-，3.5-3.9 为 B+，3.0-3.4 为 B，2.5-2.9 为 C+，2.0-2.4 为 C，低于 2.0 为 D。

### 数据限制与风险提示

基本面评级和短线/中长线评分相互独立：短线评分主要基于技术面、量价、动量和流动性；中长线评分当前仍以长期趋势和代理指标为主；基本面评级基于财务、估值、盈利能力、股息和简化 DCF。缺少财务数据时，评级会显示“数据受限”。所有结论仅使用“重点研究、优先观察、谨慎观察、等待验证、暂不优先、数据不足”等研究表述，不输出买入或卖出建议。

## 风险提示

本工具仅用于数据分析和研究辅助，不构成投资建议。模型评分依赖公开行情数据、技术指标和规则权重，不能替代独立投资判断。正式使用前应进行回测、复盘，并结合财务、公告、行业、政策、资金流等信息综合判断。
